# Activity Log

One file per day: `YYYY-MM-DD.md`. Append-only. Claude writes here after any meaningful
action so that "what did we do about X?" is always answerable.

Format:

```markdown
# 2026-09-09

## Done
- 09:40 — Drafted reply to <name> re: <thing>. Not sent.
- 11:15 — Created task "…" in <list>.

## Learned
- <fact> → filed to brain/people/work/<name>.md

## Decided
- <decision> → memory/decisions.md

## Loose ends
- <thing> → memory/open-loops.md
```
