# Template: Formal request / application

**Use for:** banks, government offices, schools, societies, landlords, insurers.

```
<Your name>
<Address>
<City, PIN>

<Date: 9 September 2026>

To,
The <Designation>
<Organisation>
<Address>

Subject: <One line, specific — "Request for closure of account no. ending 4417">

Respected Sir / Madam,

I am <name>, <one line establishing standing: account holder / resident of / parent of>.

I am writing to request <the exact thing you want, in one sentence>.

<One short paragraph of necessary context — dates, reference numbers, what has
already happened.>

<If applicable: I have enclosed the following documents:
1. <document>
2. <document>>

I would be grateful if you could <specific action> by <date>. Please contact me at
<phone> or <email> if any further information is required.

Thank you for your time.

Yours faithfully,
<Signature>
<Name>
<Any reference / customer ID>
```

**Rules for this template**
- Subject line carries the reference number. Officials file by reference, not by name.
- Ask for one thing. A second request halves the odds of the first.
- Always give a date by which you want it done, and a way to reach you.
