# Template: Follow-up on no reply

```
Subject: Re: <original subject>

Hi <name>,

Following up on the note below about <thing> — I know it's a busy stretch.

Is <the ask> still workable? If <date> doesn't suit, tell me what does and I'll work
around it.

<Sign-off>
```

**Rules**
- Never open with "just checking in" or "bumping this".
- Make it trivially answerable: a yes/no or a date.
- Second follow-up: offer an out — "happy to park this if the timing's wrong."
